# Kontaktformularens postkasse

`Code.gs` er et lille Google Apps Script, der kører på din egen Google-konto.
Det modtager beskeder fra kontaktformularen på jambazz.dk og sender dem til din
Gmail med `+github`-mærket. Din e-mailadresse står hverken i koden eller på siden.

Opdaterer du scriptet senere: **Implementer** → **Administrer implementeringer** →
blyanten → **Version: Ny version** → **Implementer**. Så beholder webappen samme URL.
